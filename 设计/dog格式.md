```dog

  君不见黄河之水天上来      # 缩进代表父子关系
  白云千载空悠悠
李商隐                    
  锦瑟无端五十弦
  望帝春心啼杜鹃
----- 昭 -----            # 左右子树分隔符: 下面是右子树; 
杜牧
  落魄江湖载酒行           
  楚腰纤细掌中轻
  												# 空白行会被忽略
●杜甫                       # ● 折叠标记
  无边落木萧萧下
  不尽长江滚滚来        
----- 父 -----            # 外部引用 
唐诗总览.dog
```

### 参考逻辑:

* 解析逻辑:
  1. 拆尾部两区 (父/形), 兼容两区任意先后
  2. 剩余正文按 `----- 昭 -----` 拆左右子树
  3. 各自用缩进栈推断父子关系; 行首 `●` 剥离后识别为折叠节点
  4. root 文本 = 文件名还原 , 不存在于文件内容中
* 第三步缩进解析逻辑:
  * 缩进容错: 兼容 tab 和不规则空格, 统一转为空格后按相对缩进量推断层级.
  * **缩进栈**: 哨兵打底, 每行弹栈找到缩进比自己小的作为父节点, 再入栈. 标准的缩进解析模式.
* 节点id逻辑:
  * 为了能够正常合并/变基文档, 因此节点id按照父子文本组织.
* 磁盘-内存转义逻辑:
  * 磁盘上用-和_代替了内存中的冒号中括号空格. 
  * 内存中的空格有分隔符的含义, 因此为了保持链接dog的完整要用中括号把链接dog括起来.

### 包装块: 

* 文本与行结构撞车时 (文本含换行 / 区标记 / 行首 `●` / 整行只有 `[` …), 盘上包成 `[[[...]]]` 块, 载入时摘掉.
* 落盘顺带把文本首空白剪掉 (`lstrip()`, 原样落盘会被当缩进), 空文本节点不写这一行 (写出去就是空行); 尾空白原样.

* 包装块语法:

```dog
      缩进 + ●? + [[[        # 开括号独占一行
内容 (逐行原样, 含空行)
]]]                          # 闭括号独占一行
```

1. 括号独占一行: 跟内容粘一起就数不清了 —— 内容以 `[` 开头时, 开括号连跑会跟它连成一段, 切不开 (实证: 试过 inline 写法, `[[[abc]]]` 往返成 `abc`)
2. 括号数 = `max(3, 内容里最长 `]` 连跑 + 1)`: 定长 3 时, 内容里恰好有一行 `]]]` 会被当闭括号, 块提前结束

| -------------------------------------------- | ------------------------ | ------------ | -------- | ------------ | ------------ | -------------------- |
| ing框 购买计划 牛奶 26-8-9-5_03_奶茶.dog ing | 26-8-9 5:03(链接dog解析) | ing框        | 购买计划 | ing          | 牛奶         | 26-8-9-5_03_奶茶.dog |

* 节点有前缀 正文 尾缀 三部分.
* 前缀有时间戳 框词(待办框)2部分.
* 尾缀有 图标 链接 2部分.
  * 其中链接有 链接名 链接dog 2部分.
  * 其中链接名存在时, 展示给用户时应该隐藏链接dog.
  * 其中链接dog需要解析其中的图标和时间戳.
